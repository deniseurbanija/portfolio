# Denise Urbanija · Portfolio

A whiteboard-style portfolio: hand-drawn bordó doodles around the intro, each one a door to a page (projects, experience, security, about, contact).

Plain HTML, CSS and vanilla JS in a single `index.html`. No build step.

## Run locally

Open `index.html` in a browser.

## Deploy

- **Vercel:** import this repo, framework preset "Other", no build command.
- **GitHub Pages:** Settings → Pages → deploy from branch `main`, folder `/`.
